# Data Cleaning and Preparation

**Organization:** SkillCraft Technology

**Task:** Task 2 — Data Cleaning and Preparation

## Objective
Clean and prepare the Global Superstore sales dataset using Python and Pandas.

## Work Completed
- Loaded the dataset into Pandas.
- Identified and handled missing values.
- Checked and removed duplicate rows.
- Converted Order Date and Ship Date to datetime format.
- Verified the cleaned dataset and data types.
- Exported the cleaned data to CSV.

## Tools Used
- Python
- Pandas
- Google Colab
- GitHub

## Project Files
- `data_cleaning_preparation.ipynb`
- `sales_data_cleaned.csv`

## Result
The cleaned dataset contains 9,800 rows and 18 columns, with no missing values remaining after the cleaning process.

Date conversion and duplicate checks were performed as part of data preparation.
